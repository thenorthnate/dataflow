# CLAUDE.md

This file provides guidance to Claude Code when working with code in this repository.

## General
1. Don't read the "IDEAS.md" file. This is for future/personal ideas and should not be used for anything.
2. Don't ever commit directly to master.
3. Only commit code if I've asked for you to do so. Normally, I will commit it myself.
4. If I ask you to make a new PLAN.md file, make sure you review at least the DESIGN.md file, the index.html file, and the files in the ./data directory before writing the plan.

## Testing
1. Always test any change that is made to the HTML code and validate it works as expected
2. When running tests, ensure each widget can be interacted with and displays properly
3. Use the existing test suite for accomplishing the above goals plus add new tests to the test suite to cover any changes you've made.
